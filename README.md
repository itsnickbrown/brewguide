# Brew Guide

Bean-first brew recipes for the Fellow Aiden, pour over and espresso, with grind settings by grinder.
Static HTML. Hosted on Cloudflare Pages. No build step.

- `brew.js`: coffee data, grinder settings, recipe logic and affiliate link config (`AMAZON_TAG`, `LINKS`).
- `index.html`, `pour-over.html`, `espresso.html`: the three tools.
